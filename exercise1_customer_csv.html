Before You Start

You need

  • Informatica IDMC access with Data Integration.
  • A Windows computer with Informatica Secure Agent installed.
  • Permission to create connections and mappings.
  • A writable local folder such as C:\Users\{username}\Documents.

You will learn

  • Secure Agent and Runtime Environment basics.
  • Flat File connections.
  • Source, Expression, Filter, and Target transformations.
  • Data-type conversion and derived fields.
  • Job execution and monitoring.
Mental model: the Informatica cloud UI does not directly read your laptop file. The Secure Agent running on Windows reads and writes the local files.

1. Prepare customers.csv

1
Open the Windows Documents folder.
Lab path: C:\Users\{username}\Documents. Replace {username} with your Windows account folder name. If your Documents folder is in a different location, use its actual path.
2
Create a new file named customers.csv.
You can use Notepad, VS Code, Excel, or another editor that can save CSV.
3
Paste this exact sample data.

"2","Mary","Jones","17","Philippines"

Save the file.
Confirm it is located at C:\Users\{username}\Documents\customers.csv.
Windows path only for this lab. Do not configure /Users/{username}/Documents; that is a macOS-style path and previously caused our FR_3000 error.

1

4

Keep Filter Condition = Simple.
4

8. Configure the Target

1
Select the Target box on the mapping canvas.

Click the final Target transformation connected after FIL_AdultOnly. Its configuration appears in the panel below the canvas.

2
Open the Target properties.

In the lower panel, select Properties, then click Target in the left-hand list. The Details area contains Connection, Object Type, and Object.

3
Choose the connection and object type.
SettingValue
ConnectionCONN_Training_Files (Flat File)
Object TypeSingle Object

Leave Use a local file for target metadata unchecked for this exercise.

4
Open the Target Object dialog.
  1. Click Select... beside the Object field.
  2. In the Target Object dialog, choose Create New at Runtime.

Create New at Runtime is an option inside this dialog. Keep Object Type set to Single Object in the underlying Target properties.

5
Enter the output filename and confirm.

In the Target Object dialog, leave Use a Dynamic File Name unchecked and enter this value in Static File Name:

adult_customers.csv

Keep the other options at their defaults for the supplied sample data, then click OK.

Back in Properties → Target, confirm that Object displays adult_customers.csv. The Operation field shows Insert and may be read-only.

The new file is created when the mapping task executes. It will be written to the folder configured in CONN_Training_Files.
6
Review the incoming fields.

In the left-hand list of the Properties panel, click Incoming Fields. Confirm that these fields arrive from the preceding transformation:

id, firstName, lastName, age, country, age_num, full_name, customer_type
7
Keep the default target field order and review Field Mapping.
  1. Click Target Fields in the left-hand list.
  2. For Do you want to modify the order of the fields while creating file at runtime?, leave No (Default) selected.
  3. Click Field Mapping in the same list. Review the mapping information shown. If a field mapping grid is displayed, confirm that each incoming field maps to its corresponding target field.

For this runtime-created target, the Target Fields screen can show only the field-order question. Seeing No (Default) here is expected for this exercise.

Troubleshooting

FR_3000 — No such file or directory
FR_3000 Error opening file [/Users/{username}/Documents/customers.csv].
Operating system error message [No such file or directory].

Cause: the Windows Secure Agent was given a macOS-style file path.

Fix: set the Flat File connection to C:\Users\{username}\Documents.

Preview Data does not show the customer rows
  • Confirm customers.csv exists in the configured folder.
  • Confirm CONN_Training_Files points to the correct Windows directory.
  • Confirm LocalTrainingRuntime is Running.
  • Confirm the Secure Agent has access to the folder.
An expression is invalid

Use the exact expressions:

TO_INTEGER(age)

firstName || ' ' || lastName

IIF(TO_INTEGER(age) >= 60, 'Senior', 'Standard')

Click Validate for each expression before closing the editor.

The mapping remains Invalid
  • Make sure Source → Expression → Filter → Target are connected.
  • Check the Source object and Flat File connection.
  • Validate all three calculated fields.
  • Check the simple filter condition age_num >= 18.
  • Check Target Fields and Field Mapping.
